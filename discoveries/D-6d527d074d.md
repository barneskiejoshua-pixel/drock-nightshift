## Problem

Run Thinking Machines Inkling-2-Mini (MoE ~26B total / ~3.4B active) locally on Apple silicon with 24 GB RAM by building a from-scratch Metal inference engine that limits resident/active memory via idle unload and persisted conversation state.

## Technique

Rust host + Metal kernels reading Unsloth UD-IQ3_XXS GGUF in place (no ggml/MLX). Menu-bar macOS app serves an OpenAI-compatible local API; after idle (default 1s) it saves conversation state to disk and unloads model working memory (instant unload), reloads on next request (warm reload ~0.1s). Supports 32k/100k context selection, network/API-key mode, drafter/speculative-decoding path noted in docs.

## Foundation

Metal/GPU compute + quantized MoE (GGUF/IQ3_XXS) inference; systems design for memory/state persistence (KV/conversation state saved to disk to enable prefix reuse and avoid reprocessing).

## Compute

Apple silicon Mac, macOS 15+; tested/dev noted on M2 MacBook Air (macOS 27.2 in notes). Needs >=24 GB RAM and ~14 GB disk for install plus space for saved state. Model served locally via bundled/server app (endpoint http://127.0.0.1:9940/v1).

## Reported

Repo states: on M2 MacBook Air ~20 tokens/s generation; examples: short-context generate 20.5 t/s, 10.5k 18.0 t/s, 29.9k 16.2–16.5 t/s; prompt reads 130 t/s (512-token) and 106 t/s (10.5k); first token with saved prefix 0.5–1.2 s; warm reload ~0.1 s. Memory (measured/quoted): waiting ~32 MB, idle after answer ~51–57 MB, active budget reported ~18 GB (5.3 GB measured server footprint + up to 12.7 GB file-backed weights) in stated test conditions (805-token prompt, 100k context limit, drafter enabled). Baseline note: patched llama.cpp b12600+Unsloth pins gave ~15 t/s in that comparison (stock upstream Metal lacking needed support at that date). These are described as individual runs, not averages; fan throttling noted after ~2.5 min heavy load.
