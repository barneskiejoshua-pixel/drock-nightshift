## Technique

1.58-bit (i2_s) ternary GGUF inference exposed as a Python ctypes SDK over a prebuilt libtermux_bitnet.so: ARM64 NEON DotProd SIMD, Vulkan offload through ameva-runtime, chunked GPU layer submission, LM-head vocab slicing, prompt-template wrapping to stop drift/word salad, and fail-fast errors instead of fake text.

## Foundation

BitNet b1.58: weights restricted to {-1,0,1}, so log2(3) ~ 1.58 bits per weight; integer/popcount or NEON sdot matmul instead of FP multiply; Vulkan/ggml-style layer offload; 2.5 s Mali watchdog fence avoided by chunking command buffers; VRAM cut by slicing FP16 LM-head rows.

## Compute

ARM64 Android/Termux or ARM64 Linux with asimddp and Vulkan; prebuilt ARM64 ELF fetched from GitHub Releases (installer.py, 15 s urllib timeout); i2_s GGUF models of 1.13 GB (2B), 635 MB (1B), 3.05 GB (7B); 4 threads; ameva-runtime >=2.0.0 required for any explicit GPU request. DRock's Windows x86-64 i5-8400 + Arc A380 is outside the target.

## Reported

README table, author-reported on Samsung Galaxy under Termux at thermal equilibrium: BitNet-2B S25 19.37, S20 7.71, A35 4.22, A53 3.26 tok/s; Falcon-E-1B S25 34.35, S20 10.76, A35 5.81, A53 4.46 tok/s; Falcon3-7B S25 8.30, S20 2.62, A53 1.74, A35 0.78 tok/s (chunk-layers 4 on the 6 GB devices). Also 30+ tok/s for the 270M embedding model on CPU mmap, 576 MB VRAM saved at vocab-slice 32768, 2.5 s Mali watchdog fence. No raw logs or timing method are published.

## Reproducibility

Python source and unittest suite are public (tests/test_engine.py uses MagicMock; tests/test_live_inference.py skips when no cached GGUF). No benchmark script, no raw measurements, no seeds in the speed table (BitNetConfig.seed defaults to 0), no model hashes; models come from Hugging Face URLs. The SIMD/Vulkan kernels are a downloaded prebuilt ELF blob, not in the repo, so the headline numbers cannot be rebuilt or reproduced from source.
